# 회차표: 1부 성인식의 해 (1~60화) [계획]

작성: 2026-10-26 자율 집필 시작 전. `setting/06_스토리_아크.md` 1부 연표, `05` 발명 예정, `08` 복선 구간을 회차 단위로 쪼갠 계획표다.
계획이지 정본이 아니다. 실제 원고와 어긋나면 원고가 우선하고, 어긋난 행은 집필 후 고친다.
"시점"은 13세 생일 아침을 D0으로 센 날수. 1부는 약 D180(추수절)에 끝난다. 평균 한 화 사흘.

## 1부 공통 원칙

- 10화 단위로 "고칠 것 하나 + 사람 하나 + 보이는 성과"를 반복한다. 보상 회차: 2, 10, 18, 25, 29, 39, 48, 56, 60.
- 감정(상태창)은 회차당 1~3개, 같은 대상 반복 금지. 하루 다섯 번 한도(감정 50회마다 하루 한 번 추가). 한도 초과는 두통 → 코피 → 실신.
- 레온은 정치에 둔하다. 10화마다 정치 실수 하나와 그 비용을 쓴다(5, 16, 21, 33, 44, 52).
- 매 화 누군가의 생활이 조금 나아진다. 힐링 장면과 긴장 장면을 같은 화에 둘 때는 긴장을 짧게.
- 승객 축은 1부에서 3할 이하: 1(프롤로그), 9(첫 조우), 12·14(이렌), 27(F02), 38·40(하르덴), 49(소문), 60(광장의 이방인).
