# 04. 인물

상태 표기: `[기초]` 원 설정 문서 기재 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

인물은 레온이 없는 곳에서도 자기 목적으로 움직인다. 전 왕·숙부·조력자의 역할만 [기초]이고, 이름과 세부는 전부 [제안]이다. 레온 본인은 `03_주인공_레온.md`.

회차 집필 시에는 이번 화에 등장하는 인물의 행만 읽는다.

## 4.1 인물 시트

### 에드릭 아르덴 (전 왕, 아버지) [역할 기초 / 이름 제안]

| 항목 | 내용 |
|---|---|
| 역할 | 유능했으나 지리적 한계로 부국 실패. 전장 사망. 아들에 대한 기대와 유산(일부 기술자 네트워크) 남김 |
| 생전의 욕망 | 협곡 너머 교역로 확보 |
| 두려움 | 아들에게 빈 왕국을 남기는 것 |
| 등장 방식 | 기록과 유언으로만 등장 |
| 1화 시점 | 북쪽 협곡 국경에서 전사. 기술자 명부(F01)와 기대를 유산으로 남김 |

### 발타르 아르덴 (숙부) [역할 기초 / 이름 제안]

| 항목 | 내용 |
|---|---|
| 역할 | 초반 주요 적대자. 왕위 찬탈 야심, 내부 세력 규합. 장기적으로 외부와 결탁 가능 |
| 욕망 | 왕위. 그 전에 섭정 지위와 재정권 |
| 두려움 | 형처럼 무능한 왕으로 기록되는 것 |
| 넘지 않는 선 | 왕족의 피를 직접 흘리지 않는다 (그래서 사고와 부적격 판정을 노린다) |
| 말투 | 정중하고 길게 말함. 레온을 "전하"가 아니라 "왕자"로 부름 |
| 1화 시점 | 재무·행정 장악. 왕족 회의에 섭정 요구 예정. 제국 쪽과 서신(F02) |
| 세력 규모 | **미정.** 정해지기 전까지 원고에서 구체 병력·인원 수를 쓰지 않는다. 확정 시 여기 기록 |

### 가렌 홀트 (기사단장, 40대) [제안]

| 항목 | 내용 |

| 역할 | 충직한 기사단장. 전 왕의 전우 |
| 욕망 | 전 왕에게 한 약속(아들을 지켜라)을 지키는 것 |

| 3화 시점 | 왕족 회의에 문 안쪽 입회. 회의 뒤 복도에서 레온을 시험 질문("왜 도랑을 보셨습니까"). 성벽 보초의 보고가 자기에게 먼저 온다는 것과 "그다음은 내가 정한다"는 것만 밝힘. 입장은 중립 유지 |

### 이렌 베슬 (견습 마법사, 17세) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 전생 지식을 이해하는 젊은 마법사·기술자. 각인 담당 |
| 욕망 | 제국 마법학원에 가지 못한 한을 실력으로 풀기 |
| 두려움 | 자기 각인이 사람을 다치게 하는 것 |
| 넘지 않는 선 | 이해 못 한 도면은 새기지 않는다 |
| 말투 | 빠르고 따지는 말투. 레온의 용어를 되묻는 유일한 인물 |
| 1화 시점 | 축소된 왕립 공방의 견습. 레온과 면식 없음 |
| 숨긴 정보 | 제국 마법학원 입학 거절 이유 (F06) |
| 4화 시점 | 미등장. 테오의 말로만 존재: "결정 일로 광산 쪽에 갔다", 돌아오면 레온 얘기를 듣고 되물을 것 [제안, 4화]. 이렌이 결정을 가져오는지 빈손인지는 02 2.7 확정과 함께 5화 전 결정 |
| 6화 시점 | 첫 등장(말미). 레온보다 머리 하나 큼, 머리를 뒤로 묶음, 옷에 광산 흙·돌가루. 빈손 귀환: 산출은 재무관 관할, 섭정 결재 없이 소형도 불가, 사흘 대기. 레온을 보자마자 연달아 되물음("쐐기가 왜 있어요. 정은 왜 꺼냈어요. 노 데워요? 장작 어디서 나요?"). "물렸다 → 틈이 닫혔다 → 결이 하나가 아니다"를 혼자 추론. 입구 바위의 가로 결을 바로 앞에서 아침 빛에 본 적 있음. 마지막 대사 "전하가 직접 봤어요?" [제안, 6화] |
| 7화 시점 | 레온의 "봤습니다 / 오늘 아침, 해가 성벽 위로 올라오기 전에"를 "그럼 보이죠"로 일단 수용. "둘로 열 번"을 제안했다가 테오의 "열흘"에 "파종"으로 즉시 셈함. 정치적 경고: "결정 하나에 사흘 안 움직인 사람이 연기 사흘이면 하루 만에 사람이 온다 / 쐐기 하나에 장작 사흘을 재무관이 믿을까". 추궁하는 눈에서 "셈하는 눈"으로. 풀무 자원, 가죽 균열을 알고 있음. 둘째 날 아침 노 점화 때 풀무를 밟음, "이틀이면 장작도 이틀 / 가죽값은요". 북쪽 갱도(판자 봉쇄, 광부는 "무너졌다", 그러나 판자 틈으로 안에서 바람이 나옴)를 레온에게 말함(F03 심음). "왜 저한테 말해요"에 "전하가 결이라는 말을 쓰니까요". 능력 의심은 "결이라는 말"에 남아 있음 [제안, 7화] |
| 8화 시점 | 2일째 아침 "이틀째예요 / 어제 말한 하루가 오늘이에요". 오스카 방문 중 풀무를 멈추고 침묵, "결재는 아직입니다"에 무응답. 오스카가 간 뒤 "하루 만에 왔죠", 근거는 "결재 기다리는 사람은 그 사람이 뭘 빨리 하고 뭘 안 하는지 셈하게 돼요". F06 표면 공개: "제국 학원도 서류를 석 달 들고 있다가 돌려줬어요. 이유는 한 줄 / 출신". 더 보태지 않음(F03과 같은 방식: 하나씩 꺼내 놓고 뒤는 남김) [제안, 8화] |

### 마르타 (시녀장) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 할머니 역할의 멘토. 레온을 어릴 적부터 키움 |
| 욕망 | 레온이 살아서 어른이 되는 것 |
| 두려움 | 레온이 아버지처럼 일만 하다 무너지는 것 |
| 넘지 않는 선 | 정치에 손을 대지 않는다 |
| 말투 | 느리고 단정적. 먹고 자는 것부터 묻는다. 단둘이 있을 때 "도련님" |
| 1화 시점 | 왕자궁 시녀장. 레온이 "달라졌다"는 것을 가장 먼저 눈치챌 인물 후보 (F04) |
| 5화 시점 | 4화 밤 귀가한 레온을 식은 보리죽으로 맞음. 빌린 연장에 "선왕께서도 빌린 것은 돌려주셨습니다". 쐐기를 들어 보고 "이걸로 돌을 치십니까, 코르빈이 칩니까"(레온이 치지 않을 것을 미리 알고 물음). 바위행을 말리지 않음("말려서 안 가실 거면 말립니다"). 새벽 빵을 레온·코르빈 각각에게 따로 줌 [제안, 5화] |
| 6화 시점 | 낮에 잠든 레온을 깨우지 않고 "해가 지기 전에 간다고 하셨습니다". 쐐기 하나가 빈 자리를 보고 묻지 않음. "빌린 걸 못 돌려주게 되면 아버지는"에 "가서 말씀하셨습니다 / 그다음은 상대가 정하는 겁니다". 레온의 땔감 약속은 아직 모름(7화 대가 발생 지점) [제안, 6화] |
| 7화 시점 | 레온이 귀가 직후 "공방에 사흘치를 보내기로 했어 / 네가 나눈 걸 내가 썼어. 묻지 않고 / 그래서 말하는 거야. 가서"로 사전 고지. 땔감 더미 앞에 한참 선 뒤 결정: "부엌 불은 끄지 않는다 / 도련님 방 불은 오늘 밤부터 끈다 / 노가 사흘 먹는 걸 방이 열흘 먹는다 / 기침이 돌아온다 / 부엌 불 옆에서 주무십시오, 이불은 제가 옮깁니다". 땔감을 단으로 묶어 코르빈 몫을 준비 [제안, 7화] |
| 8화 시점 | 밤의 기침 한 번을 듣고 묻지 않고 물을 데움. "돌아온 거 아니야"에 "예"만. 외출을 "도련님은 한 번이면 됩니다"로 제한(코르빈 두 번). 코르빈이 그 말을 공방에서 레온에게 옮김 [제안, 8화] |

### 오스카 린 (재무관) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 숙부의 수족. 재정 실무와 장부 조작 |
| 욕망 | 숙부 밑에서 재상 자리 |
| 두려움 | 장부가 공개되는 것 |
| 넘지 않는 선 | 없음 (필요하면 숙부도 버린다) |
| 말투 | 공손하고 사무적. 예산을 이유로 모든 요청을 거절 |
| 1화 시점 | 레온의 자재 요청을 막는 첫 번째 벽 |
| 2화 시점 | 왕자궁 비용 정리(땔감·등유 절반, 고기 없음, 하인 3→1, 자재 서면 신청·섭정 결재). 레온의 공방·밭 질문을 장부에 기록해 숙부에게 전달 |
| 8화 시점 | 노 점화 2일째 아침 공방에 직접 방문(장부 지참, 숙부 지시 여부 본문 미확정). 두 번 두드리고 "왕립 공방이지요". 레온→테오→이렌→노 순으로 봄. 쐐기 1·장작 사흘·왕자궁 몫·용도(도랑 머리 바위)를 적음. "막지 않는다, 다만 다음 배급 때까지 왕자궁 몫은 늘지 않는다". "수로는 영지 시설, 바위를 깨서 물이 흐르면 공사, 안 흐르면 아니다 / 물이 흐르면 서면이 올라올 것, 누가 올리든". 테오에게 봉급은 결재 뒤, 이렌에게 "결재는 아직". 성 쪽으로 돌아감(밭은 안 봄, 코르빈 관찰) [제안, 8화] |

### 테오 (왕립 공방 노장인) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 아버지의 기술자 네트워크의 마지막 생존자 |
| 욕망 | 공방이 다시 불을 켜는 것 |
| 두려움 | 도면이 제국으로 흘러나가는 것 |
| 넘지 않는 선 | 부실 공사는 하지 않는다 |
| 말투 | 말이 적고 손으로 말함. 레온의 도면을 처음 알아보는 인물 |
| 1화 시점 | 반폐된 공방에서 연장을 닦고 있음 |
| 3화 시점 | 해 질 녘 레온이 공방 쪽문을 두드림. 쪽문을 손바닥 너비만큼 열고 "누구십니까". 레온은 이름과 명부를 밝힘. 대화는 4화부터 |
| 4화 시점 | 레온을 공방 안에 들임(코르빈은 밖). 명부의 빈 메모를 "전하께서 저한테 뭘 시킬지 정하지 못하셨다"로 해석. 풀무 가죽 균열을 겨울부터 알고 있었음(가죽값 없음). 노는 꺼지지 않게만 유지("일이 들어오면 사흘을 기다리게 할 수 없다"). 레온의 숯 그림(바위 결·쐐기)을 보고 "돌 결을 먼저 그렸다"고 짚음. 그림을 닦고 "종이는 돌아다닙니다". 폐철에서 쇠 쐐기 2개와 망치 1개를 빌려 줌(갈라져도 안 갈라져도 반납 조건). 사람은 못 준다(노를 비울 수 없음). 견습(이렌)이 "결정 일로 광산 쪽"에 갔고 "전하 말을 전부 되묻는다"고 예고. 레온의 "저는 정했습니다"에 무응답 |
| 6화 시점 | 쐐기 하나가 물렸다는 말에 "돌이 물었으면 돌이 가진 겁니다". 벽의 정 셋 중 가장 짧은 것을 추가 대여(반납 조건). 금 간 폐철 쐐기는 "치면 쪼개진다"고 거부. 셋째 쐐기 제작 조건: 노 재가열 사흘, 장작 필요, 굴뚝 연기 사흘 노출. 느린 대안(정으로 빼고 둘로 열 번, 열흘, 파종 지연)도 제시. 레온이 왕자궁 땔감으로 사흘을 택하자 수락. "쐐기 하나에 장작 사흘. 비싼 쐐기입니다 / 모르십니다, 아직은요". 입구 바위를 알고 있으며 "가까이서 본 사람이 전하 전에도 있었다"(이렌). 레온의 반쯤 위장 설명에 더 묻지 않음. 이렌 귀환 시 "돌아왔습니다" [제안, 6화] |
| 7화 시점 | 이렌의 정치적 질문을 "오면 오는 거다 / 그때 말한다. 지금은 장작이 먼저다"로 유보. 둘째 날 아침 재를 걷고 가는 장작부터 골라 노 점화("처음은 가늘게"). 레온의 "바람이 반 새요, 하루 더 걸려요"에 "압니다 / 사흘이 반 새는 셈입니다 / 가죽만 있으면 이틀". 가죽값 질문에는 무응답 [제안, 7화] |
| 8화 시점 | 2일째는 굵은 장작부터. 오스카 앞에서 레온이 시킨 말만("왕자 전하께서 쐐기 하나를 주문하셨습니다"), 장작 출처는 레온에게 답을 넘김. 봉급 발언에 "압니다 / 쐐기 하나입니다". 오스카가 간 뒤 첫 정치 조언: "도랑이라고 하셨으니 이제 도랑입니다 / 물으면 쐐기 하나라고 하시면 됩니다. 쐐기는 어디에든 씁니다". 레온의 "안 흐르게 할까요"에 "그러면 쐐기는 뭣 하러 만듭니까". 레온의 미완 문장에 끄덕이지도 젓지도 않음 [제안, 8화] |
