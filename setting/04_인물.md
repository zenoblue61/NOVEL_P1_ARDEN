# 04. 인물 (v2)

상태 표기: `[지시]` 사용자 직접 지시(2026-10-24) / `[기존]` v1에서 승계 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

인물은 레온이 없는 곳에서도 자기 목적으로 움직인다. 아르덴 인물은 v1에서 대부분 승계했고 회차 기록은 v1 원고 기준이라 지웠다(`_archive/v1/setting/04_인물.md`에 보존).
전생자 6인과 118인의 체계는 `09_전생자.md`. 여기에는 회차에 자주 나오는 인물의 시트만 둔다. 회차 집필 시에는 이번 화 등장 인물의 절만 읽는다.

## 4.1 아르덴 왕가

### 에드릭 아르덴 (전 왕, 아버지) [기존]

| 항목 | 내용 |
|---|---|
| 역할 | 유능했으나 지리적 한계로 부국 실패. 1화 직후 북쪽 협곡 국경에서 전사 |
| 생전의 욕망 | 협곡 너머 교역로 확보 |
| 두려움 | 아들들에게 빈 왕국을 남기는 것 |
| 등장 방식 | 기록·유품·사람들의 기억으로만 |
| 유산 | 기술자 명부(F01), 서신 묶음 |
| 전생자 여부 | 아니다 [제안] |

### 엘런 아르덴 (동생, 9세) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 레온의 남동생. 장자가 부적격 판정을 받으면 계승권이 넘어가는 자리. 숙부에게는 섭정을 4년 더 늘리는 카드 |
| 욕망 | 형이 놀아 주는 것. 형이 고치는 걸 옆에서 보는 것 |
| 두려움 | 혼자 남는 것 (아버지·어머니를 모두 잃음) |
| 말투 | 질문이 많다. "형, 그건 왜?" |
| 기능 | 힐링 축의 시선. 레온이 고친 것을 가장 먼저 기뻐하는 사람. 숙부가 엘런을 통해 레온을 흔들 수 있다는 긴장 |
| 전생자 여부 | 아니다 (2026-10-24 확정: 전생자는 이렌, 엘런은 이번 생의 가족) |
| 장면 후보 | 이렌을 처음 본 날 "누나 눈이 형이랑 똑같아". 아이의 직감이 전생자의 공통점을 짚되 엘런은 의미를 모른다 [제안] |

### 발타르 아르덴 (숙부, 섭정) [기존, 일부 수정 제안]

| 항목 | 내용 |
|---|---|
| 역할 | 1부의 국지 적대자. 왕위 찬탈 야심. 제국 쪽과 서신(F02) |
| 욕망 | 왕위. 안 되면 엘런의 섭정을 오래 쥐는 것 |
| 두려움 | 형처럼 무능한 왕으로 기록되는 것 |
| 넘지 않는 선 | 왕족의 피를 직접 흘리지 않는다 (부적격 판정을 노린다) |
| 말투 | 정중하고 길게. 레온을 끝까지 "왕자"로 부름 |
| 전생자 여부 | 아니다. 전생자의 존재를 모른다. 제국의 서신 상대가 무엇을 원하는지도 다 알지 못한다 [제안] |
| 세력 규모 | 미정. 확정 전까지 원고에 구체 인원 금지 |
| 부별 위치 | 1부 섭정 → 1부 말 신전 탑 유폐 → 3부 탈출해 제국에 의탁 → 이후 카르델의 말이 됨 [제안] |

### 아델라 아르덴 (왕족 회의 원로, 60대) [기존]

| 항목 | 내용 |
|---|---|
| 역할 | 왕족 회의 실질 의장. 1부에선 숙부 섭정에 동의 |

## 4.2 레온의 사람들 (아르덴)

### 마르타 (시녀장) [기존]

| 항목 | 내용 |
|---|---|
| 역할 | 할머니 같은 멘토. 레온과 엘런을 키움 |
| 욕망 | 두 아이가 살아서 어른이 되는 것 |
| 두려움 | 레온이 아버지처럼 일만 하다 무너지는 것 |
| 넘지 않는 선 | 정치에 손을 대지 않는다 |
| 말투 | 느리고 단정적. 먹고 자는 것부터 묻는다. 단둘이 있을 때 "도련님" |
| 기능 | 정치 조언은 "사람" 영역. 레온의 변화를 가장 먼저 눈치챔(F04). 힐링 축의 중심 온기 |
| 전생자 여부 | 아니다 [제안]. F04(손의 감각이 전생 외할머니와 겹침)는 전생자가 아니어도 성립 |

### 테오 (왕립 공방 노장인) [기존]

| 항목 | 내용 |
|---|---|
| 역할 | 아버지의 기술자 네트워크 중 성 안의 마지막 사람. 가공·조립 |
| 욕망 | 공방이 다시 불을 켜는 것 |
| 두려움 | 도면이 제국으로 흘러나가는 것 |
| 넘지 않는 선 | 부실 공사는 하지 않는다 |
| 말투 | 말이 적고 손으로 말함. "종이에 그리지 마십시오. 종이는 돌아다닙니다" |
| 감정사와의 관계 | 레온이 만져 보고 말하는 결함을 손과 소리로 먼저 알고 있는 경우가 많다. 상태창이 정보 우위를 다 주지 않는다는 증거 |
| 전생자 여부 | 아니다 [제안] |

### 이렌 베슬 (견습 마법사, 17세) [기존 + 전생자 설정 제안]

| 항목 | 내용 |

## 4.6 세력 관계도 (1화 시점)

```
                 [제국] 황제 카르델 (전생자, 최초)
                    |  명단청 세라 (전생자)
                    |  서신 (F02)
  [레온의 사람들]   v
  마르타 ─┐     발타르 (숙부, 섭정) ── 오스카 (재무관)
  테오   ─┼─> 레온 아르덴 (장자, 13세, 상태창) ── 엘런 (동생, 9세)
  이렌*  ─┤        ^
  코르빈 ─┘        │ 자금 (저울질)
  가렌 (중립)      모르간 (길드)
                                  * 파편 보유 전생자
  [대륙] 도시국가: 엘리아스(전생자) / 군사 왕국: 브록(전생자) / 제국 탑: 오르반(전생자, 기장)
```

조력자 획득 순서 [제안]: 마르타 → 코르빈 → 테오 → 이렌 → 가렌 → 모르간.
