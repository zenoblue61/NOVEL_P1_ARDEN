# 04. 인물

상태 표기: `[기초]` 원 설정 문서 기재 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

인물은 레온이 없는 곳에서도 자기 목적으로 움직인다. 전 왕·숙부·조력자의 역할만 [기초]이고, 이름과 세부는 전부 [제안]이다. 레온 본인은 `03_주인공_레온.md`.

회차 집필 시에는 이번 화에 등장하는 인물의 행만 읽는다.

## 4.1 인물 시트

### 에드릭 아르덴 (전 왕, 아버지) [역할 기초 / 이름 제안]

| 항목 | 내용 |
|---|---|
| 역할 | 유능했으나 지리적 한계로 부국 실패. 전장 사망. 아들에 대한 기대와 유산(일부 기술자 네트워크) 남김 |
| 생전의 욕망 | 협곡 너머 교역로 확보 |
| 두려움 | 아들에게 빈 왕국을 남기는 것 |
| 등장 방식 | 기록과 유언으로만 등장 |
| 1화 시점 | 북쪽 협곡 국경에서 전사. 기술자 명부(F01)와 기대를 유산으로 남김 |

### 발타르 아르덴 (숙부) [역할 기초 / 이름 제안]

| 항목 | 내용 |
|---|---|
| 역할 | 초반 주요 적대자. 왕위 찬탈 야심, 내부 세력 규합. 장기적으로 외부와 결탁 가능 |
| 욕망 | 왕위. 그 전에 섭정 지위와 재정권 |
| 두려움 | 형처럼 무능한 왕으로 기록되는 것 |
| 넘지 않는 선 | 왕족의 피를 직접 흘리지 않는다 (그래서 사고와 부적격 판정을 노린다) |
| 말투 | 정중하고 길게 말함. 레온을 "전하"가 아니라 "왕자"로 부름 |
| 1화 시점 | 재무·행정 장악. 왕족 회의에 섭정 요구 예정. 제국 쪽과 서신(F02) |
| 세력 규모 | **미정.** 정해지기 전까지 원고에서 구체 병력·인원 수를 쓰지 않는다. 확정 시 여기 기록 |

### 가렌 홀트 (기사단장, 40대) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 충직한 기사단장. 전 왕의 전우 |
| 욕망 | 전 왕에게 한 약속(아들을 지켜라)을 지키는 것 |
| 두려움 | 기사단이 봉급 때문에 숙부 편으로 갈리는 것 |
| 넘지 않는 선 | 명령 없이 칼을 뽑지 않는다 |
| 말투 | 군인 말투. 레온을 시험하듯 질문함 |
| 1화 시점 | 중립에 가깝다. 레온을 어린 책벌레로 보고 있음 |
| 전환 조건 | 11~20화, 군사 왕국 약탈대 위협 앞에서 레온이 성벽 보강안을 들고 직접 설득할 때 |

### 이렌 베슬 (견습 마법사, 17세) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 전생 지식을 이해하는 젊은 마법사·기술자. 각인 담당 |
| 욕망 | 제국 마법학원에 가지 못한 한을 실력으로 풀기 |
| 두려움 | 자기 각인이 사람을 다치게 하는 것 |
| 넘지 않는 선 | 이해 못 한 도면은 새기지 않는다 |
| 말투 | 빠르고 따지는 말투. 레온의 용어를 되묻는 유일한 인물 |
| 1화 시점 | 축소된 왕립 공방의 견습. 레온과 면식 없음 |
| 숨긴 정보 | 제국 마법학원 입학 거절 이유 (F06) |

### 모르간 텔 (상인 길드장) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 상인 길드. 자금과 외부 정보 공급 |
| 욕망 | 동쪽 도시국가의 중간 마진을 떼어내는 것 |
| 두려움 | 지는 편에 돈을 걸었다가 파산하는 것 |
| 넘지 않는 선 | 계약은 지킨다 (이익이 있는 한) |
| 말투 | 숫자로 말함. 약속을 문서로 받아 내려 함 |
| 1화 시점 | 숙부와 레온 양쪽을 저울질 중 |
| 전환 조건 | 21~26화, 마나 엔진 물레방아 가동으로 가공품 수출 가능성이 보일 때 자금 제공 |

### 마르타 (시녀장) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 할머니 역할의 멘토. 레온을 어릴 적부터 키움 |
| 욕망 | 레온이 살아서 어른이 되는 것 |
| 두려움 | 레온이 아버지처럼 일만 하다 무너지는 것 |
| 넘지 않는 선 | 정치에 손을 대지 않는다 |
| 말투 | 느리고 단정적. 먹고 자는 것부터 묻는다. 단둘이 있을 때 "도련님" |
| 1화 시점 | 왕자궁 시녀장. 레온이 "달라졌다"는 것을 가장 먼저 눈치챌 인물 후보 (F04) |

### 오스카 린 (재무관) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 숙부의 수족. 재정 실무와 장부 조작 |
| 욕망 | 숙부 밑에서 재상 자리 |
| 두려움 | 장부가 공개되는 것 |
| 넘지 않는 선 | 없음 (필요하면 숙부도 버린다) |
| 말투 | 공손하고 사무적. 예산을 이유로 모든 요청을 거절 |
| 1화 시점 | 레온의 자재 요청을 막는 첫 번째 벽 |

### 테오 (왕립 공방 노장인) [제안]

| 항목 | 내용 |
|---|---|
| 역할 | 아버지의 기술자 네트워크의 마지막 생존자 |
| 욕망 | 공방이 다시 불을 켜는 것 |
| 두려움 | 도면이 제국으로 흘러나가는 것 |
| 넘지 않는 선 | 부실 공사는 하지 않는다 |
| 말투 | 말이 적고 손으로 말함. 레온의 도면을 처음 알아보는 인물 |
| 1화 시점 | 반폐된 공방에서 연장을 닦고 있음 |

### 어머니 [미정]

원 설정 문서에 언급 없음. 사망·부재·생존 중 결정 필요. 생존해 있다면 왕족 회의에서 섭정 후보가 되므로 숙부의 섭정 취임 논리가 바뀐다. 결정 전까지 원고에서 언급하지 않는다.

## 4.2 호칭 규칙 [제안]

| 화자 → 대상 | 호칭 |
|---|---|
| 모두 → 레온 (즉위 전) | 왕자 전하 |
| 모두 → 레온 (즉위 후) | 폐하 |
| 숙부 → 레온 | 끝까지 "왕자" |
| 마르타 → 레온 (단둘이) | 도련님 |
| 레온 → 숙부 | 숙부님 (공식 석상에서는 섭정 각하) |
| 레온 → 가렌 | 단장 |
| 레온 → 테오·이렌 | 이름 |

## 4.3 인물별 지식 분포 (1화 시점) [제안]

| 사실 | 레온 | 숙부 | 가렌 | 이렌 | 마르타 | 독자 |
|---|---|---|---|---|---|---|
| 레온의 전생과 설계의 눈 | 안다 | 모른다 | 모른다 | 모른다 | 모른다 (변화만 눈치챔) | 안다 |
| 숙부의 찬탈 의도 | 짐작 | 안다 | 의심 | 모른다 | 의심 | 안다 |
| 숙부의 외부 접촉 (F02) | 모른다 | 안다 | 모른다 | 모른다 | 모른다 | 단서만 |
| 기술자 명부 (F01) | 모른다 (유품 정리 중 발견) | 모른다 | 모른다 | 모른다 | 안다 | 레온과 함께 |
| 마나 결정 대광맥 (F03) | 모른다 | 모른다 | 모른다 | 모른다 | 모른다 | 모른다 |

독자가 숙부의 의도를 알고 레온은 짐작만 하는 구조이므로, 초반 긴장은 "숙부가 무엇을 할까"가 아니라 "레온이 언제 알아차리고 무엇을 준비하나"에서 나온다.

## 4.4 세력 관계도 (1화 시점)

```
            에드릭 (전 왕, 사망)
                  | 유산 (F01)
  [레온의 조력자]  v             [숙부 세력]
  마르타 ----> 레온 아르덴 <==대립==> 발타르 (숙부, 섭정)
  테오   ----> (13세 왕자)              |
  이렌   ---->      ^                 오스카 린 (재무관)
  가렌(중립) ->     | 자금 (저울질)
               모르간 텔 (상인 길드)

  [주변국] 제국(남): 협곡 통제권 / 상업 도시국가(동): 광석 독점 / 군사 왕국(북): 국경 충돌
```

조력자 획득 순서(제안): 마르타 → 테오 → 이렌 → 가렌 → 모르간. 이 순서가 1아크 전반의 회차 구성이다.
