## 레온의 현재

| 항목 | 값 |
|---|---|
| 상태 | 열 내림. 전생 기억 전체 보유. 4화 첫 두통 경험(하루 여섯 번째 감정), 잠으로 회복 |
| 상태창 | 1단계(물건). 맨손 접촉 + 보려는 의도일 때만 뜸. 자기 손·손목은 시도했으나 아무것도 안 뜸(4화). 수리로 상태가 바뀐 물건은 새로 셈 |
| 감정 누적 | 14회 (3화 탁자·등잔 / 4화 벽돌·모루·줄·받침대·청동·띠 두른 축 / 5화 보리 자루·나무 말). 하루 한도 5회를 레온이 알고 셈. 초과 비용 1단계(두통) 경험 |
| 아는 것 | 자기가 123명 중 하나(32C). 옆자리 32B 남자(손등 흉터)가 팔을 잡았음. 상태창의 정체는 모르나 "자기 안에 있는 것은 아니다"라고 느낌. 숙부가 전령보다 먼저 전사 소식을 알았음(의미는 모름). 성인식 날짜가 수확에 달림. 하루 한도 다섯. 옛 도랑: 머리 바위, 샘 마름, 돌담만 남음(브렌 전언, 직접 못 봄). 창고 바닥은 해마다 습함 |
| 배운 것 | 마르타: "짧게 말하기", "사람 앞에서 유품을 열지 않기", "말하기 전에 한 번 멈추기", "아프면 멈추기". 5화 정치 실수(숙부 앞에서 도랑을 먼저 말함) 뒤 "말하기 전에 마르타에게 먼저" 약속. 가렌의 질문 "몇을 먹이는가"에 "지금은 아무도" |
| 자원 | 마나 결정 0. 왕자궁 유지비 삭감(하인 급여 1인분, 액수 미표기). 성문은 섭정부 허가로만(마르타가 신전 참배 경로를 암시). 아버지 유품: 외투(왼쪽 소매 찢김), 단검, 인장 반지, 서신 묶음, 기술자 명부 넉 장(가렌 등 기사는 없음). 왕자궁 몫 보리는 이레마다 창고에서 올라옴 |
