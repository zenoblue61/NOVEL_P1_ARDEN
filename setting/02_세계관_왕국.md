# 02. 세계관: 대륙, 아르덴, 제국, 마나, 성인식 (v2)

상태 표기: `[지시]` 사용자 직접 지시(2026-10-24) / `[기존]` v1에서 승계 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

중세 대륙. 마법과 마도공학이 있고, 마도공학은 아직 초기 단계다. [지시]
아르덴은 대륙의 최약소국이다. 부족한 것은 자원이 아니라 자원을 꺼내고 옮기고 오래 쓰게 하는 기술이며, 재료·기계를 아는 주인공이 통하는 이유다.

## 2.1 대륙과 주요국

| 국가 | 위치 | 성격 | 아르덴과의 관계 | 상태 |
|---|---|---|---|---|
| 아르덴 왕국 | 북쪽 산악·협곡 | 대륙 최약소국 | 주인공의 나라 | [지시] 최약소국 / [기존] 지리 |
| 제국 | 남쪽 평원 | 대륙 최강국. 황제 카르델(전생자). 마도공학이 가장 앞섬 | 아르덴을 공물국·완충지로 취급 | [기존] 위치 / [지시] 황제 |
| 상업 도시국가 | 동쪽 강 하류 | 무역·금융. 아르덴 광석을 헐값에 사서 가공 | 유일한 무역 창구 | [기존] |
| 군사 왕국 | 북쪽 산맥 너머 | 국경 협곡에서 상습 충돌. 전 왕이 전사한 전장의 상대 | 위협 | [기존] |
| 그 밖의 소국 | 미정 | 전생자 분포가 넓으므로 3부 이후 필요할 때 추가 | | [미정] |

## 2.2 아르덴 왕국

| 항목 | 내용 | 상태 |
|---|---|---|
| 지리 | 산악과 협곡에 둘러싸임. 농업 생산성 낮음 | [기존] |
| 수도 | 아르덴 성. 협곡 입구를 내려다보는 고지대. 방어엔 좋으나 물이 귀함. 성 아래 계단식 밭과 협곡 바닥의 강 | [기존] |
| 농업 문제 | 물은 협곡 바닥, 밭은 사면. 물을 위로 올릴 수단이 없어 가물마다 흉작 | [기존] |
| 옛 수로 | 성벽 아래 맨 위 밭에서 시작해 돌담 따라 내려가는 도랑. 샘이 말라 수년째 마름. 입구 바위 막힘, 둘째 밭 모퉁이 돌담 붕괴, 넷째 밭 역구배 | [기존, 재사용] |
| 광산 | 북쪽 산중 철·구리·마나 결정 광맥. 갱도 좁고 배수 불량, 사고 잦음 | [기존] |
| 생활 실태 | 겨울 난방 부족, 곡식 창고 습기·쥐 피해, 우물 도르래 낡음, 위생 열악. 힐링 축의 "고칠 거리" 목록 | [제안] |
| 인구·재정·병력 | 수치 베이스라인은 2.7 | [제안] |

## 2.4 마나와 마도공학

| 규칙 | 내용 | 상태 |
|---|---|---|
| 마법 | 존재하나 고위 마법은 희귀. 아르덴엔 고위 마법사 없음 | [지시] 존재 / [기존] 희귀 |
| 마도공학 | 마나 결정을 동력원으로 쓰는 공학. 대륙 전체가 초기 단계. 제국이 가장 앞서 있으나 카르델의 전생 지식(조직·생산) 덕이지 설계 능력 덕은 아님 | [지시] 초기 / [제안] 제국 |
| 마나 결정 | 북쪽 광맥 채굴. 주변 마나를 천천히 흡수·저장, 각인 회로로 방출. 크기·순도가 출력 결정. 소모품. 과부하 시 균열, 균열 간 결정은 터짐 | [기존] |
| 각인 | 마법사가 결정에 방출 경로를 새김. 기존 각인은 발광·발열 수준 | [기존] |
| 감정사와의 접점 | 감정사는 결정의 순도·균열·잔량을 읽는다(1단계). 각인은 못 한다. 레온에게 마법사(이렌)가 필요한 이유 | [제안] |
| 결정 가격·통제 | 소형 1개 약 3금화. 아르덴 산출은 재무관 관할, 섭정 결재 필요 | [기존] |

## 2.5 성인식과 왕위 계승

| 규칙 | 내용 | 상태 |
|---|---|---|
| 성인식 | 13세 생일 이후 첫 추수절 아침. 그 전 정식 즉위 불가 | [기존] |
| 성인식의 해 | 13세 생일부터 추수절까지. 이 해에 주인공에게만 상태창이 열림 | [지시] |
| 공백기 | 아버지가 성인식 전에 전사. 생일(초봄)부터 추수절까지 약 6개월 | [기존] |
| 장자와 동생 | 레온은 장자. 동생 엘런(9세)이 있다. 장자가 부적격이면 계승권이 동생에게 넘어가고, 동생은 성인식까지 4년이 남으므로 섭정이 길어진다. 숙부가 "부적격 판정"을 노리는 동기 | [지시] 장자 / [확정 2026-10-26 자율 채택] 동생·계승 논리 |
| 섭정 | 왕족 회의가 가장 가까운 성년 남자 왕족(숙부)을 섭정으로 세움. 재정·인사·군사 | [기존] |
| 신전 관할 | 왕자들의 신변과 성인식 집행은 왕립 신전 관할. 숙부가 직접 해칠 수 없는 이유 | [기존] |
| 찬탈 경로 | 레온 사망 또는 왕족 회의의 "통치 부적격" 판정. 숙부는 후자를 노림 → 생활 개선의 가시적 성과가 정치적 생존 수단 | [기존] |
| 추수절 | 수확 직후 가을 축제. 성인식은 신전 앞 광장에서 백성이 보는 가운데 | [기존] |
| 즉위 후 | 16세 전까지 왕족 회의 3/5로 보좌 섭정 가능. 폐위는 전원 일치 + 대사제 승인 | [기존] |

## 2.6 전생자에 관한 세계 규칙 [지시 + 제안]

전생자 개별 명단·관계는 `09_전생자.md`.

| 규칙 | 내용 | 상태 |
|---|---|---|
| 출처 | 미지의 자기장 증폭 지대에서 추락한 여객기의 탑승자 123명(조종사·승무원 포함) 전원 | [지시] |
| 출생 분산 | 같은 순간에 죽었으나 이세계 출생은 약 31년에 걸쳐 흩어짐. 카르델이 최초(44년 전 출생), 레온은 거의 마지막(13년 전 출생) | [지시] 분산 / [제안] 연수 |
| 기억 | 6명은 전생 기억 전체. 118명은 파편(냄새·노래·숫자·좌석 번호·한 사람의 얼굴 같은 조각) | [지시] |
| 인식 | 전생자는 전생자를 알아본다. 처음 눈이 마주치면 양쪽 모두 기압이 떨어질 때처럼 귀가 먹먹해진다. 누구인지는 모르고 "같은 쪽"이라는 것만 안다 | [지시] 인식 / [제안] 감각 |
| 인식의 결과 | 양방향이라 숨을 수 없다. 레온이 제국 사람을 직접 만나는 것 자체가 위험이 된다 | [제안] |
| 세계의 인지 | 일반인은 전생자의 존재를 모른다. 제국 상층부 일부만 "황제가 특정한 사람들을 찾는다"는 사실을 안다 | [제안] |
| 상태창 | 123명 중 레온에게만 있다. 이유는 장기 미스터리(F21) | [지시] |

## 2.7 수치 베이스라인 (1화 시점) [기존 승계, 목표 구간만 6부로 재배분]

원고에 숫자가 처음 등장하는 회차에서 확정한다.

| 항목 | 1화 | 2부 끝(150화) | 4부 끝(360화) | 6부 끝(480화) |
|---|---|---|---|---|
| 왕국 인구 | 약 4만 | 약 6만 | 약 10만 | 약 15만 |
| 수도 인구 | 약 8천 | 약 1만 5천 | 약 3만 | 약 5만 |
| 기사 / 병사 | 60 / 400 | 80 / 800 | 120 / 2,000 | 150 / 3,000 |
| 광부 | 약 120 | 약 250 | 약 450 | 약 600 |
| 마나 결정 월 산출 (소/중/대) | 3~5 / 0~1 / 0 | 30 / 5 / 0 | 120 / 25 / 3 | 200 / 40 / 6 |
| 연간 세수 (금화) | 약 1,200 (공물 400) | 약 4,000 | 약 15,000 | 약 30,000 |
| 겨울 동사자·아사자 | 해마다 발생 | 0을 목표 | 0 | 0 |

화폐: 금화·은화·동화. 1금화 = 100은화. 숙련 장인 월급 2~3금화.
"겨울 동사자·아사자"는 힐링 축의 핵심 지표다. 1부 첫 겨울에 처음으로 줄어드는 장면을 보상으로 쓴다.
