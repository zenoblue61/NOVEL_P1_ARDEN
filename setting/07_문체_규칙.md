# 07. 문체 규칙

상태 표기: `[기초]` 원 설정 문서 기재 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

원 설정 문서에 시점·시제·수위 규정이 없어 대부분 [제안]이다. 사용자가 지정한 분량(5,000~5,500자)과 시점 선택지(1인칭 또는 3인칭 제한)는 [기초]. 확정하면 1화부터 적용한다.

## 7.1 시점·시제

| 항목 | 규칙 | 상태 |
|---|---|---|
| 시점 | 3인칭 제한 시점, 레온 고정 (작업 정본). **추천: 1화 전 3인칭으로 확정.** 3아크 전쟁·외교 장면에서 레온이 없는 결과(전장, 제국 회의)를 요약 서술로 넘길 수 있고, 1인칭은 280화 내내 레온의 속말로만 세계를 보여야 해 2·3아크의 규모를 감당하기 어렵다 | [기초] 선택지 / [제안] 3인칭, 1화 전 확정 필요 |
| 다른 인물의 내면 | 표정·행동·말로만 드러낸다. 확정 서술 금지 | [제안] |
| 숙부 시점 막간 | 쓰지 않는다. 숙부의 수를 독자도 레온과 같은 속도로 알게 한다 | [제안] |
| 시제 | 과거 시제 | [제안] |

## 7.2 분량·호흡

| 항목 | 규칙 | 상태 |
|---|---|---|
| 회차 분량 | 본문 공백 포함 5,000~5,500자. 제목·기록 제외. 도구로 센다 | [기초] |
| 문단 | 짧은 문단, 모바일 가독성. 대사가 바뀌면 문단을 나눈다. 모든 문장을 한 줄씩 끊어 리듬을 획일화하지 않는다 | [제안] |
| 장면 수 | 필요한 만큼만. 회차마다 같은 장면 수나 기승전결을 강제하지 않는다 | [제안] |
| 전투·정치 대립 | 짧게. 위치·거리·목표·행동·결과가 따라가지게 | [기초] |
| 발명·영지 변화 | 가시적 성과를 구체적으로. 물이 오르는 밭의 넓이, 걸리는 시간, 사람들의 반응 | [기초] |

## 7.3 설계의 눈과 공학 설명

| 항목 | 규칙 | 상태 |
|---|---|---|
| 발동 장면 | 회차당 한 번. 시각 이미지(힘의 흐름, 약한 고리가 어둡다)로 짧게. 웹툰화를 염두에 둔 장면이므로 생략하지 않는다 | [제안] |
| 공학 설명 밀도 | 원리는 한 문장, 효과는 한 장면. 수식·현대 전문 용어는 레온의 속말에만 등장하고, 인물들은 이 세계의 말로 바꾸어 부른다 | [제안] |
| 설명 대사 | 레온이 남에게 설명해야 하는 상황에서만. 서로 아는 정보를 대사로 설명하지 않는다 | [제안] |

## 7.4 초반 훅과 사이다 속도 [기초 + 제안]

- 1~30화는 "위기 하나 + 발명 하나 + 눈에 보이는 성과"를 10화 단위로 반복한다.
- 위기는 늦어도 1화 안에 제시한다. 정보 없는 일상으로 시작을 지연하지 않는다.
- 성과는 적절한 시점에 실제로 지급한다. 승리뿐 아니라 이해, 인정, 관계 진전도 보상이다.
- 회차 말미는 결정의 결과, 새 문제, 감정의 여운, 발견 중에서 고른다. 매화 위기 직전에서 자르거나 허위 반전으로 끝내지 않는다.
- 직전 회차의 강한 미해결 장면을 다음 화에서 건너뛰지 않는다.

## 7.5 수위·로맨스·금지 요소

| 항목 | 규칙 | 상태 |
|---|---|---|
| 수위 | 전투 사상자는 쓰되 고문·잔혹 묘사는 피한다. 13세 주인공이므로 성적 묘사 없음 | [미정] (제안값) |
| 로맨스 | 노맨스 또는 가벼운 로맨스 선택 가능. 남성향 성장·경영 중심 유지 권장. 1아크에서는 로맨스 없음 | [기초] / 최종 [미정] |
| 금지 요소 | 새 능력·갑작스러운 조력자로 위기 해소 금지. 레온이 정치를 "갑자기 잘하게" 되는 전개 금지. 원고 안에 해설·평가·태그 삽입 금지 | [제안] |

## 7.6 문장 금기 [제안]

- 같은 정보를 대사 → 독백 → 서술로 반복하지 않는다.
- 추상적 수식, 비슷한 비유, 불필요한 부사, 번역투를 줄인다.
- 인물별 말투는 어휘·문장 길이·호칭·숨기는 정보로 구분한다. 유행어·과장된 말버릇으로 차별화하지 않는다.
- 감정은 자극 → 해석 → 반응 → 선택의 인과가 보이게 쓰되, 모든 단계를 설명문으로 풀지 않는다.
