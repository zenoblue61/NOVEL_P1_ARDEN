# 05. 마도공학과 발명 목록 (v2)

상태 표기: `[지시]` 사용자 직접 지시(2026-10-24) / `[기존]` v1에서 승계 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

v2의 발명은 "영지를 살기 좋게 만드는 것"이 기준이다 [지시]. 그래서 v1보다 생활 개선 품목이 앞에 오고, 무기는 뒤로 밀린다.
레온은 감정(진단)한다 → 원인을 해석한다 → 재료·사람·시간을 모은다 → 만든다. 감정 규칙은 `03_주인공_레온.md` 3.3, 마나 규칙은 `02_세계관_왕국.md` 2.4.

## 5.1 공통 제작 규칙

| 규칙 | 내용 | 상태 |
|---|---|---|
| 감정 ≠ 완성 | 상태창은 무엇이 문제인지 알려 줄 뿐. 재료·인력·시간 없이는 못 만든다 | [제안] (v1 "도면 ≠ 완성" 승계) |
| 재료공학의 활용 | 레온의 강점은 재료다. 같은 설계라도 "무엇으로 만드는가"로 해결하는 장면을 우선한다 (합금 비율, 열처리, 흙·석회 배합, 나무 건조) | [제안] |
| 분업 | 레온 감정·설계 → 테오 가공·조립 → 이렌 각인 → 영지 사람들 설치·운용 | [기존] |
| 실패 허용 | 첫 시제품은 한 번 실패하거나 부분 성공. 상태창은 맞지만 레온의 해석이 틀리는 실패가 기본형 | [기존] + [제안] |
| 결정 소모 | 결정은 소모품. 과부하 시 균열. 소형(순도 중) 펌프 가동 시 반나절에 약 2할 소모, 쉬면 하루 약 1할 회복(주변 마나 흡수). 반나절 가동 + 이틀 휴지면 잔량 유지 | [기존] 소모품 / [제안] (18~19화) 수치 |
| 기술 범위 | 1부는 순수 공학·재료 위주. 마나는 소형 결정 한두 개 수준. 부가 갈수록 마나 의존도 상승 | [기존] |
| 이익 충돌 | 각 발명은 반드시 누군가의 이익을 건드린다. 누구에게 부탁해야 하는지 미리 정한다 | [기존] |
| 성과 표기 | 효과는 생활의 숫자로 보인다: 겨울 동사자 수, 물이 닿는 밭의 수, 창고 곡식이 썩지 않은 날수 | [제안] |
| 열처리 용어 | 이 세계 장인 말: 담금질(달궈서 물에), 되돌림(담금질 뒤 낮게 다시 데움 = 뜨임. 색으로 잼: 밀짚색이 기본, 돌 쐐기는 그 전 연한 노란색). "열처리"는 레온의 전생 말이라 이렌이 되물음(9화) | [제안] (7·9화) |
