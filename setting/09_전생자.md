# 09. 전생자: 123인의 승객 (v2)

상태 표기: `[지시]` 사용자 직접 지시(2026-10-24) / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

123명은 같은 순간에 죽었고, 이 대륙에 서로 다른 해에 태어났다. 이 작품의 장기 이야기는 그 123명이 서로를 찾아내는 과정이다.

## 9.5 왜 레온은 아직 들키지 않았는가 [제안]

인식 규칙상 레온은 제국 사람을 한 번만 마주쳐도 들킬 수 있다. 1~2부 힐링 구간을 지키는 장치:

| 장치 | 내용 |
|---|---|
| 최약소국 | 제국 사절은 해마다 공물만 받고 간다. 왕자를 직접 만날 일이 없다 |
| 늦은 출생 | 카르델은 31년간 "새 전생자는 더 오지 않는다"고 판단하고 있다 |
| 명단청의 우선순위 | 세라는 제국 안과 도시국가부터 훑는다. 아르덴은 목록 끝 |
| 레온의 선택 | 2부부터 레온은 제국 사절 앞에 나가지 않는다(대리 접견). 이 선택이 외교 비용이 된다 |
| 균열 | 2부 말, 아르덴이 "살기 좋은 나라"로 소문나면서 명단청이 아르덴을 목록 위로 올린다 |
