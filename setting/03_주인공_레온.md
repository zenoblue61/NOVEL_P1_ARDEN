# 03. 주인공: 레온 아르덴 (v2)

상태 표기: `[지시]` 사용자 직접 지시(2026-10-24) / `[기존]` v1에서 승계 / `[제안]` 채택 전 / `[미정]` 작가 결정 필요

레온은 뭐든 만져 보고 뜯어 봐야 직성이 풀리는 사람이다. 이번 생에서는 그 손이 닿는 것마다 상태창이 정체를 알려 준다. 문제는 고칠 것이 너무 많고, 고칠 손과 재료가 너무 적다는 것이다.

### 상태창 표기 형식 [제안]

숫자와 항목은 감정 대상에만 붙인다. 레벨·스탯·퀘스트 같은 게임식 성장 표기는 쓰지 않는다(힐링 톤 유지). 원고에서는 아래 형식만 쓴다.

```
[감정] 녹슨 도르래 축
재질: 연철 (불순물 많음)
결함: 축 안쪽 실금 1
수명: 약 한 달
개선: 청동 덧대기
```

| 규칙 | 내용 |
|---|---|
| 노출 빈도 | 회차당 상태창 박스 1~3개. 같은 대상 반복 금지 |
| 레온 본인 | 자기 자신은 감정되지 않는다(2단계 이후에도). 장기 미스터리와 연결 |
| 오류 | 상태창은 틀리지 않지만 레온의 해석은 틀릴 수 있다. 실패의 근거 |
| 성장 표기 | 감정 누적 횟수와 단계 변화만 상태창에 뜬다 (예: "감정 100회. 2단계 조건 하나 충족") |

## 3.4 집필 시 체크

- 해법은 늘 "만져 보고 → 원인을 알고 → 무엇이 부족한가"에서 출발한다. 부족한 것(재료·사람·돈·시간) 중 하나는 반드시 남에게 부탁해야 얻는다.
- 감정 결과는 짧은 상태창 박스로 보여 주고, 해석은 레온의 속말 한두 문장으로.
- 사람 감정(2단계)은 남용하지 않는다. 상대가 느끼므로 관계 비용이 든다.
