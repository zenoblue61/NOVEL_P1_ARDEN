# 08 문체 규칙과 용어표

기초 문서에 시점·시제·수위 규정이 없어 아래는 전부 제안이다. 확정하면 1화부터 적용한다. CLAUDE.md의 표가 요약본이고 이 파일이 상세본이다.

## 서술

| 항목 | 규칙 |
|---|---|
| 시점 | 3인칭 제한 시점, 레온 고정. 다른 인물의 속마음은 표정·행동·말로만 드러낸다. 숙부 시점 막간은 쓰지 않는다 (숙부의 수를 독자도 레온과 같은 속도로 알게 하기 위해) |
| 시제 | 과거 시제. 대사 안의 시제는 자유 |
| 분량 | 본문 공백 포함 5,000~5,500자. 제목·제작 기록 제외. `scripts/charcount.py`로 실측 |
| 문단 | 짧은 문단. 대사가 바뀌면 문단을 나눈다. 모든 문장을 한 줄씩 끊어 리듬을 획일화하지 않는다 |
| 장면 수 | 필요한 만큼. 회차마다 같은 장면 수나 기승전결을 강제하지 않는다 |
| 회차 끝 | 결정의 결과, 새로운 문제, 감정의 여운, 발견 중에서 고른다. 모든 회차를 위기 직전에서 자르지 않는다 |
| 전투 | 위치·거리·목표·행동·결과가 따라가지는 서술. 짧게 |
| 정치·설계 | 대사 중심. 길게 써도 된다. 레온이 상대의 감정을 놓치는 순간을 한 번은 넣는다 |

## 도면 장면 (설계의 눈)

- 회차당 최대 1회. 웹툰화를 염두에 둔 시각적 장면이므로 "힘의 흐름과 구조선이 겹쳐 보이고 약한 고리가 어둡게 보인다"를 변주해 짧게 쓴다.
- 원리는 한 문장, 효과는 한 장면. 수식과 현대 전문 용어는 레온의 속말에만.
- 레온이 남에게 설명해야 하는 상황에서만 공학 설명을 대사로 푼다. 그때 상대(이렌·테오)가 이 세계의 말로 되묻게 한다.

## 용어표 (레온의 속말 → 이 세계의 말)

| 레온의 속말 | 인물들의 말 | 비고 |
|---|---|---|
| 펌프, 양수기 | 물올림 틀 | 테오가 붙인 이름 (제안) |
| 엔진 | 돌림심 | 이렌이 붙인 이름 (제안) |
| 베어링 | 구름쇠 | |
| 회로, 각인 회로 | 길 새김 | 기존 각인은 "빛 새김"·"열 새김" |
| 버트리스, 아치 | 받침벽, 홍예 | |
| 유압 | 물힘 | |
| 마나 결정 | 마나석 | 일상 호칭. 공식 문서는 "결정" |
| 설계의 눈 | (명칭 없음) | 레온만 속으로 부름. 남에게 말하지 않는다 |

새 용어가 원고에서 생기면 이 표에 추가하고 progress.md의 신규 설정 제안에 적는다.

## 인물별 말투 샘플

| 인물 | 특징 | 샘플 |
|---|---|---|
| 레온 | 짧고 건조. 해법부터 | "물은 아래 있고 밭은 위에 있습니다. 올리면 됩니다." |
| 발타르 | 정중하고 길다. "왕자" | "왕자께서 공방 같은 곳에 드나드신다는 말을 들었습니다. 선왕의 상중에 그런 곳은 어울리지 않지요." |
| 가렌 | 군인 말투. 시험하는 질문 | "그 벽이 버틴다는 걸 전하께서 어떻게 아십니까." |
| 이렌 | 빠르고 따지는 말투. 되묻는다 | "길 새김이요? 그건 빛도 열도 아닌데, 뭘 새기라는 건데요." |
| 모르간 | 숫자. 문서 | "수익의 삼 할. 문서로 주십시오. 말은 바람입니다." |
| 마르타 | 느리고 단정적. "도련님" | "도련님, 그 손으로 뭘 하시든 먼저 드시고 하세요." |
| 오스카 | 공손, 사무적, 거절 | "예산 항목에 없습니다, 전하. 섭정 각하의 결재가 필요합니다." |
| 테오 | 말이 적다. 손으로 말한다 | "……이건 누가 그렸소." |

## 금지 목록

- 새 능력·갑작스러운 조력자·숨겨진 예외로 위기 해소.
- 레온이 정치를 갑자기 잘하게 되는 전개. 정치적 성장은 조력자를 통해서, 실패를 거쳐서.
- 같은 정보를 대사 → 속말 → 서술로 반복.
- 인물끼리 다 아는 설정을 독자에게 설명하려고 주고받는 대사.
- 앞 회차의 끝을 다음 화에서 무효화하는 낚시. 장면 중간의 기계적 절단.
- 번역투, 추상적 수식, 같은 비유의 반복, 불필요한 부사.
- 원고 안의 작업 해설, 평가, 태그, 독자 조언.
