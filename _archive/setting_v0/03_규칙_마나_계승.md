# 03 규칙: 마나·마도공학·설계의 눈·왕위 계승

마도공학은 마법이 아니라 동력 공학이다. 마법사가 없어도 돌아가지만, 마나 결정 없이는 돌아가지 않는다. 그래서 결정을 누가 캐고 누가 가공하는가가 정치 문제가 된다.

## 마나 체계

| 규칙 | 내용 | 상태 |
|---|---|---|
| 마나의 존재 | 마나는 존재하나 고위 마법은 희귀하다 | 기초 |
| 마도공학의 핵심 | 마나 결정 또는 마나 흐름을 동력원으로 삼는다. 레온은 현대 기계공학 원리로 마나를 효율적으로 변환·증폭하는 장치를 설계한다 | 기초 |
| 제작 분업 | 레온이 설계하고 기술자와 마법사가 협력해 제작한다 | 기초 |
| 마나 결정의 성질 | 북쪽 광맥에서 채굴. 주변 마나를 천천히 흡수해 저장하고, 각인된 회로를 통해 방출한다. 크기와 순도가 출력을 결정 | 제안 |
| 각인 | 마법사가 결정에 방출 경로를 새기는 작업. 기존 각인은 단순 발광·발열 수준. 레온의 도면이 각인을 "회로"로 바꾼다 | 제안 |
| 비용과 위험 | 결정은 소모품. 과부하하면 균열이 가고, 균열 간 결정은 터진다. 마나 흐름(지맥)을 직접 쓰는 장치는 설치 위치가 고정되고 출력이 계절에 따라 변한다 | 제안 |
| 고위 마법사 | 제국에 소수 존재. 아르덴에는 없다. 마도공학이 퍼지면 이들의 위상을 위협한다 (3아크 갈등 후보) | 제안 |

## 설계의 눈 (원리 투시)

| 항목 | 내용 | 상태 |
|---|---|---|
| 효과 | 대상(기계, 건물, 마법 장치, 자연 구조)을 보면 작동 원리와 개선 도면이 자동으로 떠오른다 | 기초 |
| 원천 | 전생 경험 + 현생 마나 친화도 시너지 | 기초 |
| 한계 1 | 재료·인력·시간 필요. 도면만으로 즉시 완성 불가 | 기초 |
| 한계 2 | 과사용 시 두통·피로. 대형 프로젝트는 단계적 진행 | 기초 |
| 한계 3 | 정치적 반대, 자원 부족, 외부 위협이 속도를 제한. 조력자(기술자, 기사, 상인) 필수 | 기초 |
| 한계 4 | 마법 지식은 학습 필요. 초기에는 현대 공학 위주, 점차 마도공학으로 융합 | 기초 |
| 발동 조건 | 대상을 직접 눈으로 봐야 한다. 전언·그림·기억만으로는 발동하지 않는다 (레온이 현장에 가야 하는 이유, 위험에 노출되는 이유) | 제안 |
| 보이는 것 | 대상 위에 힘의 흐름과 구조선이 겹쳐 보이고, 약한 고리가 어둡게 보인다. 개선안은 "떠오른다"에 가깝고 보정은 레온의 몫 | 제안 |
| 비용 단계 | 작은 대상(도구, 문) 하루 여러 번. 중간(물레방아, 성문) 하루 1~2회, 이후 두통. 대형(성벽 전체, 광산) 1회에 다 보지 못하고 나눠 봐야 하며 코피·실신 위험 | 제안 |
| 성장 | 마나 지식을 배울수록 마법 장치의 도면이 더 선명해진다. 사람은 보이지 않는다 (정치는 능력 밖) | 제안 |
| 비밀 유지 | 능력의 존재를 숨긴다. 공식 설명은 "아버지가 남긴 책과 장인들에게 배웠다". 들키면 이단·괴물 프레임으로 공격받을 수 있다 | 제안 |

설계의 눈은 도면을 주지만 각인은 할 수 없다. 레온은 마법사가 필요하고, 마법사는 레온의 도면을 이해할 수 있어야 한다. 이 상호 의존이 조력자 관계의 기반이다.

## 성인식과 왕위 계승

| 규칙 | 내용 | 상태 |
|---|---|---|
| 성인식 시기 | 13세 생일 이후 첫 추수절 아침 | 기초 |
| 즉위 조건 | 성인식 전에는 정식 즉위 불가 | 기초 |
| 공백기 | 아버지가 성인식 전에 전사해 공백기가 생긴다 | 기초 |
| 공백기 길이 | 레온의 13세 생일은 초봄, 아버지 전사 소식은 생일 직후. 추수절까지 약 6개월 | 제안 |
| 공백기 통치 | 왕족 회의가 섭정을 세운다. 관례상 가장 가까운 성년 남자 왕족, 즉 숙부가 섭정이 된다 | 제안 |
| 섭정의 권한 | 재정·인사·군사 지휘. 단, 왕자의 신변과 성인식 집행은 왕립 신전이 관할한다 (숙부가 레온을 대놓고 해칠 수 없는 이유) | 제안 |
| 찬탈의 경로 | 숙부가 왕위를 얻는 합법적 길은 둘. 레온이 성인식 전에 죽거나, 왕족 회의가 레온을 "통치 부적격"으로 판정하는 것. 숙부는 후자를 노리고, 그래서 레온의 가시적 성과가 정치적 생존 수단이 된다 | 제안 |
| 추수절 | 수확 직후 가을 축제. 성인식은 신전 앞 광장에서 백성이 보는 가운데 치른다. 올해 수확량이 레온의 정당성을 증명하는 자리 | 제안 |
